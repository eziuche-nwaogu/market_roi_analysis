# Marketing ROI Analysis Using Simple Linear Regression

## Project Overview This project analyzes marketing advertising data using Simple Linear Regression with Python and statsmodels. The objective is to determine which advertising channel has the strongest impact on Sales. --- 

## Technologies Used - Python - pandas - numpy - matplotlib - seaborn - statsmodels - scipy --- 

## Installation Install required libraries using: pip install pandas numpy matplotlib seaborn statsmodels scipy --- 

## Project Tasks - Data cleaning - Exploratory Data Analysis (EDA) - Correlation analysis - OLS regression modeling - Regression diagnostics - Business interpretation and recommendations ---
